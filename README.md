# 指定联络人 · 课堂原型

> **课堂原型，非汇丰官方。** 这是课程作业的概念原型，不是任何银行的 App，不会转账，也不会发短讯。

在手机浏览器打开即可使用，包括：

- **长者端**：嵌入银行 App 的「指定联络人」全部画面（登记、情境模拟、管理、大额转账暂停、智安存）
- **联络人端**：模拟短讯收件箱，汇丰通知混在推广和诈骗短讯中
- **测试模式**：开始页、隐藏的主持人面板、问卷、自动记录，结果送到 Google 表格

测试流程见 [`guide.html`](guide.html)（测试主持卡）。

## 一、发布到 GitHub Pages

1. 在 GitHub 新建一个仓库。**名称不要用 HSBC 或汇丰**，例如 `tc-prototype`。
2. 把这个文件夹里的全部文件上传到仓库根目录（包括 `.nojekyll`）。
3. 打开仓库的 **Settings › Pages**，Source 选 **Deploy from a branch**，Branch 选 `main`、文件夹选 `/ (root)`，按 Save。
4. 等一两分钟，网址会是：`https://你的用户名.github.io/仓库名/`
5. 把网址做成二维码发给组员。

> 免费账号的 GitHub Pages 要用**公开仓库**。如果你有 GitHub 学生包（含 GitHub Pro），可以用私有仓库。

## 二、在手机上「装」成 App

- **iPhone**：用 Safari 打开 › 分享 › **加到主画面**
- **Android**：用 Chrome 打开 › 右上角 ⋮ › **加到主屏幕**

之后从主画面的图标打开，会全屏显示，像一个 App。

## 三、设定 Google 表单（收集结果）

1. 新建一个 Google 表单，加 5 条「段落」题，顺序和名称如下：
   参与者编号、角色、摘要、问卷答案、详细记录
2. 在表单的「回复」页，按「链接到 Google 表格」，以后结果会自动进表格。
3. 按右上角 ⋮ › **获取预填链接**，每题随便填一个字，按「获取链接」，复制链接。
4. 链接里会有 5 个 `entry.数字=…`，按题目顺序记下这 5 个 `entry.数字`。
5. 打开 `config.js`：
   - `formAction`：表单网址，把最后的 `/viewform` 换成 `/formResponse`
   - `fields` 里按顺序填上 5 个 `entry.数字`
6. 把改好的 `config.js` 上传到仓库，覆盖原来的文件。

没有设定表单也可以用：结果会保存在手机上，测完按「复制结果」发给组长，或在开始页「导出全部记录」（CSV）。

> 送出方式无法确认表格一定收到。第一次正式测试前，先自己测一场，打开表格看看有没有新的一行。

## 四、主持人面板

测试中**长按顶部「课堂原型，非汇丰官方」那条**（或连按 5 下）：

- 直接跳到某个画面（例如跳过登记，直接测转账暂停）
- 切换联络人接不接电话、字体大小、显示事后指引短讯
- 结束操作，填写问卷
- 放弃这一场

## 五、自动记录了什么

| 想知道 | 记录 |
| --- | --- |
| 看不看得懂（A） | 介绍页停留时间；问卷两题 |
| 愿不愿意开（B） | 是否完成登记、停在哪一步、按了几次「以后再说」、第 2 步关掉哪几项；问卷一题 |
| 金额（C） | 接受建议还是修改，改成多少 |
| 暂停时怎么做 | 第一个按哪个按钮、隔了几秒、打电话结果、有没有取消 |
| 减少保护 | 尝试调高金额、关掉通知、更换或取消联络人，以及最后是提交还是放弃 |
| 联络人（D） | 短讯打开顺序、在汇丰短讯停留几秒、有没有打开诈骗短讯；问卷两题 |

只记录参与者编号，不记录姓名和电话。页面里的名字和号码都是虚构的。

## 六、注意

- 网页已设定不让搜索引擎收录（`noindex`）。请不要改网页标题，也不要把网址公开张贴。
- 每个画面顶部都有「课堂原型，非汇丰官方」，请不要删除。
- **测试结束后**，到 Settings › Pages 关掉网站，或把仓库删除。
